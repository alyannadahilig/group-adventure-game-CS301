1. Which merge conflicts occurred?
I only encountered a merge conflict regarding the .gitignore file due to Student A (Jerome) pushing a .gitignore file to main. Because I was the first member to merge my branch to main, I did not encounter any merge conflicts within the files that all members worked on.

2. How were they resolved?
I resolved the conflict in the .gitignore file by keeping the changes that both Student A and B made.

3. Which Git commands were most useful?
I found git status to be the most useful as it helped me remind myself which files had changes and if they were staged to be committed

4. What was the most challenging part of collaboration?
The most challenging part for me was overthinking the order in which we merged. At first, I thought we would have to heavily coordinate to do the merges in order, but since all of us worked on different features, it did not matter the order in which we merged. I ended up merging first, even if I was assigned to be Student B.

5. What would you do differently next time?
Next time, I would wait for someone else to merge first so that I would be able to work on more complicated merge conflicts. Though I gained experience using git last quarter and practiced merge conflicts by myself, this was my first time actaully collaborating with others as the class I learned git in last quarter was an asynchronous class.
